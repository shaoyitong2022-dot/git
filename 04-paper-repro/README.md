# Phase 4 — Paper Reproduction & Original Contribution

Goal: by junior spring/summer, produce **one first-author reproduction-with-extension** that
becomes the centerpiece of the PhD application. Target venues: NeurIPS workshop, ICML workshop,
or a country-level conference. Stretch goal: arXiv preprint + workshop poster.

## Candidate papers (shortlist, refined over time)

- QML: a recent PennyLane demo extension, or a quantum kernel scalability paper
- NQS: extension of a NetKet result to a new lattice / Hamiltonian
- Equivariant NN: MACE/Allegro on a new chemistry dataset
- Quantum error correction + ML: neural surface-code decoder

## Contents

- `notes/` — reading notes (LaTeX or Markdown) on chosen paper
- `repro/` — faithful reproduction code
- `ext/` — original extension experiments
- `writeup/` — report / poster / draft
